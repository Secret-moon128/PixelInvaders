# Pixel Invaders

## Mini Project for OOSD Lab

Pixel Invaders is a 2D arcade-style shooting game developed as part of the Object Oriented System Design (OOSD) Laboratory project. The game is inspired by classic space shooter games where the player controls a spaceship and defeats waves of incoming enemies.

The project demonstrates the implementation of object-oriented programming concepts such as inheritance, polymorphism, encapsulation, abstraction, and event-driven game logic using Java.

---

## Project Objective

The objective of this mini project is to design and develop a simple arcade game while applying core OOSD principles and Java programming concepts.

The project focuses on:
- Game development fundamentals
- Object-oriented design
- Event handling
- Collision detection
- GUI rendering
- Game loop implementation

## OOSD Concepts Implemented

### Encapsulation
Game objects such as players, enemies, and bullets maintain their own states and behaviors.

### Inheritance
Different game entities extend common base classes for code reuse and modularity.

### Polymorphism
Methods are overridden for customized enemy and gameplay behavior.

### Abstraction
Game mechanics are abstracted into separate classes and modules.

### Event Handling
Keyboard listeners are used for player movement and shooting controls.

## Installation and Execution

Clone the repository:

```bash
git clone https://github.com/Secret-moon128/PixelInvaders.git
```

Open the project in IntelliJ IDEA or any Java IDE.

Compile and run:

```bash
javac Main.java
java Main
```

Or simply run the `Main.java` file directly from the IDE.
